## v0.1.1

这一版集中修「全屏播放时控制条用不了 / 看不见」这一串问题。
同步与本地计算的规矩没有任何变化：**视频字节不出本机，哈希仍由本机 Rust(WASM) 计算**。

### 修好的问题

1. **全屏后调不了进度、倍速、音量。**
   之前全屏只把画面那一块放大了，控制条留在全屏之外，全屏里等于没有控制条。
   现在全屏的是「整块播放器舞台」，控制条跟着一起进全屏。
2. **全屏后控制条不出现（Firefox）。**
   旧写法把 `:fullscreen` 和 `:-webkit-full-screen` 写在同一条规则里；Firefox 不认带前缀的
   那个伪类，按 CSS 规则**整条选择器列表失效**，连 `:fullscreen` 那半截一起被丢掉。
   现在全屏布局由脚本加 `.is-fs` 类驱动，各家浏览器一致。
3. **控制条点得到却看不见。**
   视频在不少机器上会被送进硬件叠加层（显示控制器直接扫描输出），网页浮层被它整个盖住：
   命中测试还认得浮层（所以点得到），但画不出来。现在浮层会自己提层并加 `backdrop-filter`，
   同时把视频从叠加层里踢出来（微小透明 + 圆角 + 提层），默认就是浮层。
4. **控制条出现时画面被挤动。**
   控制条的位置在窗口模式收起时不占高度；「滑出」模式在全屏时该高度常驻预留——
   无论哪种模式，画面尺寸和位置都不会在调进度时跳动。

### 控制条的两种显示方式（顶栏「控制条」按钮切换，选择记在本机）

- **浮层（默认）**：进度、倍速、音量叠在画面底部，鼠标一动浮现、静止约 2.6 秒淡出，
  不占位置、画面完全不动。
- **滑出**：控制条挪到画面下方、不叠在画面上，任何显卡/浏览器都画得出来（代价是占一条高度）。
  浮层在你这台机器上如果仍然画不出来，切到这个即可。

顶栏另有两枚辅助：**状态胶囊**（显示中 / 已隐藏 / 已收起）和 **「诊断」面板**
（界面版本、指针事件计数、控制条 opacity / pointer-events / 命中测试），
「看不到控制条」时打开它就能一眼看出卡在哪一步。

- `sync_video_player-v0.1.1-x86_64-unknown-linux-musl.tar.gz`
