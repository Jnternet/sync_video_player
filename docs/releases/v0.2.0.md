## v0.2.0

这一版加了一整套键盘快捷键，并把「按住快进」做成了房间级操作。
同步与本地计算的规矩没有任何变化：**视频字节不出本机，哈希仍由本机 Rust(WASM) 计算**。

### 快捷键（顶栏「⌨ 快捷键」或按 `Q` 调出提示面板）

| 键 | 作用 | 范围 |
| --- | --- | --- |
| `Q` | 显示 / 隐藏快捷键提示面板（Esc、点面板外也能关） | 本机 |
| `F` | 全屏 / 退出全屏 | 本机 |
| `M` | 静音 / 取消静音（与顶栏复选框联动） | 本机 |
| `W` `S` 或 `↑` `↓` | 音量 ±10%；音量 ≤10% 时每次 ±2%，方便微调 | 本机 |
| `A` `D` 或 `←` `→` | 后退 / 前进 5 秒 | 同步 |
| 按住 `D` 或 `→` | 超过 0.2 秒全场 2 倍速快进，松开恢复原速 | 同步 |

几个要点：

- **跳转**走的是拖进度条那条路（发 `seek`），房间里所有人一起跳。
- **快进**把房间倍速改成 2、松手再改回来。服务端 `set_rate` 会重算基准位置，
  所以变速不会让大家的位置错开；还回去的是「按住之前那个倍速」——房间本来 1.5 倍速就还
  1.5 倍，中途被别人改过倍速则不覆盖别人的选择。
- **音量与静音只在本机生效**，协议里没有这两个字段，一个字节都不发出去。
- 在输入框、下拉框、滑块里打字或拖滑块时快捷键自动让位（焦点在复选框、按钮上照常生效）。
- 不到 0.2 秒的短按不算快进，是「前进 5 秒」；只有按住过线才进 2 倍速。

### 兜底：不会让全场卡在 2 倍速

- 按住快进时窗口失焦（切标签 / Alt+Tab）收不到 `keyup`，会把倍速还回房间。
- 关页面/刷新时 `fetch` 会被浏览器掐掉，改用 `sendBeacon` 再发一次同样的还原请求。
- 系统按键自动重复（长按不放的连续事件）不算新的一次按键，不会把音量一路冲到底。

### 顺手修的两处

1. **倍速下拉框以前只发不收**：别人改倍速、或自己按住快进时，框里还写着 1 倍。
   现在它跟着房间走；房间倍速不在下拉选项里时（协议允许 0.25~4）保持原样，不会变成空框。
2. **点完「静音」复选框再按 `W` 没反应**：原来只要焦点在 `input` 上就放行给控件。
   现在只有文本类输入框、下拉框、滑块会让位。

### 产物

- `sync_video_player-v0.2.0-x86_64-unknown-linux-musl.tar.gz`
  —— 静态链接（musl），任何 Linux 发行版直接跑；解包后 `./sync_video_player`。
- `sync_video_player-v0.2.0-x86_64-pc-windows-gnu.zip`
  —— Windows exe（只依赖系统 DLL），双击即用；同一局域网的人用浏览器打开它打印的地址即可。

前端检查（DOM 接线 / 同步策略 14 项 / 控制条浮现淡出 32 项 / 键盘快捷键 67 项）、
端到端冒烟 46 项，并且用发布产物本身再跑了一遍冒烟测试——全部通过。
