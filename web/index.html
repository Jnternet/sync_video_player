哈希由 Rust 编译成的 WebAssembly 在你本机计算，文件字节不离开这台设备，也不经过网络。

在任意机器上运行 sync_video_player hash "文件路径" --json，把输出粘贴到这里。此模式不传输任何文件字节，但需要你自己保证文件一致。

3 · 参与者

    说明

    • 同步的是控制信息：文件哈希、大小、播放/暂停、时间戳、倍速。
    • 哈希由 Rust(WASM) 在各自本机计算；文件字节永远不出本机。
    • 每个用户播放自己磁盘上的文件（blob: 本地播放），视频流量为 0。
    • 平时各自按本机时钟播放，不会为了追平偏差而主动跳转或变速。
    • 只有当有人触发播放/暂停/跳转/倍速（即产生新的控制信息）时，才会对齐一次。
    • 需要时可用「⟲ 对齐」手动拉平；也可以打开「本地自动微调」用变速慢慢磨平。
